# Assistify

**AI-Powered HR Assistant with Enterprise Knowledge Search**

Final-year B.Tech project. An AI assistant that answers employee HR questions from the company's own uploaded policy documents, reads that employee's live data, takes actions (leave applications, support tickets), and enforces who can see what.

---

## ⚠️ Current status: planning — no application code yet

This repository currently contains **documentation only**. Architecture and scope are locked pending owner sign-off; implementation has not started. This is deliberate — see the working agreement in `docs/HANDOFF.md`.
